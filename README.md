# Hello Godot With UART

> Petit atelier pour apprendre la programmation avec des mini-voitures dans la vraie vie, depuis Godot 😉  

Le but de l'atelier est d'apprendre à piloter de petites voitures via une connexion Wi-Fi, avec son ordinateur ou sa tablette, depuis Godot.   

Soit avec cette voiture, que j'ai achetée pour animer des ateliers :   
<img width="990" height="688" alt="image" src="https://github.com/user-attachments/assets/c0be2eba-1596-49af-8053-66a2eb682f8f" />

Vous pouvez utiliser le Bluetooth pour la piloter, mais je conseille fortement le Wi-Fi avec de l'UART pour la rapidité de transmission.   
Vous trouverez un tutoriel pour apprendre à le faire vous-même chez vous. Je vous le fournirai durant l'atelier.

Le but est de s'amuser en apprenant à coder (à parler aux machines) depuis Godot.    

Cela permet de faire d'une pierre trois coups :   
- S'initier à la programmation.   
- S'initier au jeu vidéo.   
- S'initier à la robotique.   
  
Ça reste un atelier de vulgarisation pour enfants.    
On va rester sur les bases 😉   


Pour continuer à apprendre la programmation et le jeu vidéo après l'atelier, je vous invite à vous entraîner sur un petit écran que j'aime vraiment : les SSD1306.   
Je proposerai donc une petite journée d'initiation pour apprendre à les utiliser.
